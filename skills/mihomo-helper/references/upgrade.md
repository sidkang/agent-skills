# 升级核心

1. 用户要求升级后，按 [安装](install.md#下载) 查询最新稳定版、阅读发布说明，探测下载地址并校验文件；下载期间保持旧核心运行。
2. 记录版本、程序/配置路径、自启任务状态，备份旧 exe 和配置。确认新资产适用当前 Windows 架构。
3. 在授权的维护窗口停止本次管理的任务及进程，**只替换二进制**，保留配置、provider 缓存和状态。核对任务路径及防火墙规则，按需先手工启动再恢复自启。
4. 检查版本、TUN/DNS、直连、GitHub、指定代理服务及 provider 更新。失败则停止新版、恢复旧 exe 和先前任务状态；配置仅在确有改动且获确认时回滚。

若升级需要调整配置，遵守 [路径与修改约定](../SKILL.md#路径与修改约定)。交付时说明实际运行版本、检查结果及未解决问题。
